# Using The Repository

Start with the demo, then choose whether to inspect the published results or
run the full paper suite.

- [Reproduction](reproduce.md): installation, demo and paper commands, public
  result data, and manuscript compilation.
- [Configs](configs.md): TOML schema, variants, sweeps, experiment families, and output destinations.
- [Notebooks](notebooks.md): guided demo and paper workflows, Colab setup,
  execution controls, and output locations.
- [Running experiments](running.md): CLI options, outputs, checkpoints, and analysis.
- [Diagnostics](diagnostics.md): smoke checks and non-paper controls.

For measured findings and limitations, see [Results](../results/README.md).
The model's formal definition is in [the manuscript](../manuscript/main.tex).
