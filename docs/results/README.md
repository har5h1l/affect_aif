# Results

Start with [Findings](findings.md) for the paper's measured comparisons,
uncertainty, and limitations. Then use [Provenance](provenance.md) to trace a
number or figure back to its source table and run.

| Read | Purpose |
|---|---|
| [Findings](findings.md) | Current paper results and what they do or do not establish. |
| [Provenance](provenance.md) | Run revisions, figure inputs, statistical methods, and excluded data. |
| [Diagnostics](diagnostics.md) | Older or supplementary controls, separate from paper evidence. |

## Data

- [Paper results ZIP](../../paper_results.zip): frozen trajectories and summaries.
- [Checksum](../../paper_results.zip.sha256): verify the downloaded archive.
- [Paper result folders](../../results/paper/): browsable compact tables and manifests.
- [Manuscript source tables](../manuscript/source_tables/): inputs to paper figures.

For extraction, analysis, or fresh runs, follow the
[reproduction guide](../guide/reproduce.md). Config definitions and output
locations are in the [config guide](../guide/configs.md).
