# IWAI 2026 camera-ready results

`affect_aif-iwai2026-camera-ready-results.zip` is the frozen public data
package for the accepted IWAI 2026 manuscript. It contains the complete
`results/paper/` tree: compact summaries, provenance manifests, analysis
artifacts, and ten canonical row-level `results.csv` tables.

The included paper results use the shared six-valued social action and linear
affective-charge update. Historical factorized-action and squared-charge
generations are intentionally excluded from the public package and retained
only in the server archive.

Verify the downloaded ZIP with
`affect_aif-iwai2026-camera-ready-results.zip.sha256`. The individual canonical
CSV digests are recorded in `CANONICAL_RESULTS.sha256` and included in the ZIP.
